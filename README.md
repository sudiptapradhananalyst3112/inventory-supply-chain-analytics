# 📦 Inventory & Supply Chain Management Analysis

## 🎯 Project Overview
A comprehensive Data Analytics dashboard designed to optimize warehouse efficiency, monitor regional product demand, and track fulfillment performance. This solution helps supply chain managers minimize backorders and manage transportation overhead.

## 💡 Key Business Insights Discovered
* **Warehouse Over-Utilization:** Current warehouse utilization sits at **34.08%**, indicating significant open capacity for stock expansion.
* **Fulfillment Bottlenecks:** Identified **248 pending orders** and **114 cancellations** that require process optimization in the distribution chain.
* **Regional Costs:** The **West and North regions** drive the highest transportation costs, specifically within the Clothing and Furniture product categories.

## 🛠️ Tech Stack & Skills Demonstrated
* **BI Tooling:** Power BI (DAX modeling, interactive dashboarding)
* **Data Engineering:** SQL / Power Query (Data cleaning, handling null values, schema modeling)
* **Metrics Tracked:** Inventory Turnover Ratio, Days Sales of Inventory (DSI), Lead Time Averages
